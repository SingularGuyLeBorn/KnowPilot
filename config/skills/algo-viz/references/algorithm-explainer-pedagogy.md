# 算法讲解动画应包含什么

> 动画 = 一帧帧「会动的板书」。先定每一帧要讲清的事实，再画；不要先画炫技再补字。

## 1. 必备内容清单（缺一即不合格）

| 层 | 必须有 | 说明 |
|---|---|---|
| **问题** | 开场 1 句「要解决什么」 | 观众 3 秒内知道为什么看 |
| **符号表** | 本片用到的符号 / 变量一览 | 如 $r_t(\theta)=\pi_\theta/\pi_{old}$；$t$ 是时间步 |
| **公式** | 主公式至少出现一次，且与图联动 | 公式高亮的项 ↔ 图上高亮的元素，同帧对齐 |
| **状态机** | 输入状态 → 动作 → 中间态 → 可见结果 | 每拍都要有「变了什么」 |
| **对比** | 至少一处前后 / 左右 / 对错对照 | AR vs Diffusion、clip 内外、有无 mask |
| **讲解旁白条** | 底部或侧栏短句（静音可懂） | 不是装饰字幕，是推理步骤 |
| **直觉句** | 「所以可以……」「否则会……」 | 机制讲完立刻给 takeaway |
| **边界/例外** | 一句 caveat（可选但推荐） | 如「示意尺度」「忽略常数项」 |

## 2. 时间轴建议（16:9，约 15–30s）

1. **Hook（0–2s）**：问题 + 一帧最大信息量 hero（已排好版的终态缩略）
2. **Setup（2–5s）**：符号表 + 初始状态（公式淡入，图就位）
3. **Mechanism（主体）**：每 3–5s 一拍  
   - 公式某一项高亮  
   - 对应图形元素动作  
   - 旁白条换句  
   - 结果定格半拍再 handoff
4. **Compare（可选 3–6s）**：对照另一算法 / 边界情况
5. **Takeaway（末 2s）**：一句话结论 + 主公式定格

## 3. 公式怎么放（特化）

- **主公式用 KaTeX 风格文本或 SVG path 清晰字形**，字号 ≥ 画面高度的 4%，勿糊成装饰。
- **同一时刻只强调一个子表达式**（颜色/下划线/放大），其余降对比。
- **禁止**「整屏只有抽象色块、公式只在文章里」——动画内必须自带公式。
- 推导步：每步 = 旧式 → 高亮变换 → 新式（像板书擦写，保留上下文）。

## 4. 讲解旁白条（特化）

每拍固定结构（可写在 choreography JSON）：

```text
[动作] 把 r 推到 1+ε 之外
[结果] clip 生效，advantage>0 时不再加大更新
```

规则：

- 一句 ≤ 28 个汉字；避免「如图所示」空话。
- 旁白变化与关键动画 **同帧起步**（±4 帧）。
- 静音可懂：关掉声音仍能靠旁白条 + 公式跟上。

## 5. 视觉系统（白底教学默认）

见微算法讲解片默认 **浅色纸面**，对齐文章阅读：

| 角色 | 建议色 |
|---|---|
| 背景 | `#FFFFFF` 或 `#F7F8FA` |
| 主字 | `#1A1D26` |
| 次要 | `#5C6578` |
| 强调 A | `#2563EB` |
| 强调 B / 成功 | `#059669` |
| 警告 / 越界 | `#DC2626` |
| 面板 | `#F1F5F9` + 细边框 `#E2E8F0` |

禁止默认黑底霓虹（那是口播/品牌片，不是教程板书）。  
饱和色只标语义态（选中、越界、并行），不要铺满装饰渐变。

## 6. 像「绘图 skill」一样画每一帧

把每一关键帧当成一张独立教学插图验收：

1. **焦点唯一**：这帧眼睛该停在哪？
2. **标签贴对象**：箭头/括号指向具体 token、节点、曲线段。
3. **信息密度**：一张静帧应能截图进幻灯片仍可读。
4. **连续性**：跨帧同一对象保持形状/颜色/位置语义（persistent object registry）。
5. **因果可见**：动作发生后，结果必须在画面上变（数、色、形、位置至少一项）。

分镜表字段（可写入 `choreography`）：

```json
{
  "id": "clip-hit",
  "startFrame": 220,
  "endFrame": 300,
  "statement": "r 越出上界时被夹回 1+ε",
  "formulaHighlight": "\\min(r A, (1+\\epsilon) A)",
  "actors": ["ratio-dot", "clip-band", "formula"],
  "caption": "越界 → clip 生效，不再加大更新",
  "setup": "点在 band 内",
  "action": "点右移穿出上沿",
  "result": "点贴在 1+ε，公式第二项高亮",
  "handoff": "切换到 A<0 对称情形"
}
```

## 7. 文章嵌入契约

动画负责「动的机制」；文章仍应有：

- 完整公式推导（`$...$` / `$$...$$`）
- 文字讲解段落
- ` ```viz ` 只挂 composition，不把源码塞进 md

若动画内零公式、零旁白条 → **验收失败**，须重做，不得只改文章糊弄过去。
