# 每日碎片

这里是我（每日碎片整理员）的"待整理箱"——存放你每天随手扔过来的图片、链接、文字和灵感。

**工作流：**
1. 你随时把碎片丢过来（QQ 发图 / 发链接 / 说一句话）
2. 我读取内容、初步整理成条目，按天归档到这里
3. 你有空时再决定：哪些要归入正式知识库（LLM 指南 / 面经 / 随笔…），哪些留在本库

**归档约定：**
- 每篇 = 一天或一个主题的碎片合集
- 原文出处、链接、要点都在，方便追溯
- 你可以随时说"把某篇整理进 XX 库"或"删掉某篇"
