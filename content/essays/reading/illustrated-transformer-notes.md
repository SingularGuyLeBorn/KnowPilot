# 〈The Illustrated Transformer〉读书笔记

> 原文：https://jalammar.github.io/illustrated-transformer/（Jay Alammar, 2018）
> 本笔记是个人对原文的梳理与延伸思考，非翻译。

---

## 核心思想

**一句话**：用"图解 + 直觉优先"的方式，把 Transformer 从黑盒拆到张量、再从张量拆到机制，让读者在没有深厚背景的情况下也能建立对"注意力即一切"的直觉。

这篇文章之所以成为深度学习史上被引用最多的博客之一，是因为它回答了一个关键问题：**为什么 Transformer 能用 attention 取代 RNN/CNN 却训练得更快**？它不像论文那样先摆公式，而是先讲"每个词在 encoder 里走自己的路径，前馈层无依赖所以可并行"——把并行化的来源讲成了故事的起点。

---

## 机制拆解

按原文顺序，把每个部件"是什么"记一遍：

| 部件 | 是什么 |
|---|---|
| Encoder/Decoder 堆叠 | 6 层结构相同但不共享权重的 block；encoder 2 子层，decoder 3 子层 |
| Self-Attention | 编码某词时查看输入序列其他位置，把相关词的"理解"烘焙进当前表示 |
| Q/K/V 向量 | 嵌入 × 三个训练矩阵得到；维度 64 < 嵌入 512（架构选择，控制多头计算量） |
| 注意力分数 | $q$ 与各 $k$ 点积 → 除以 $\sqrt{d_k}$ → softmax → 加权求和 $v$ |
| 多头注意力 | 8 组 Q/K/V 权重 → 8 个 $Z$ → 拼接 × $W^O$；扩展关注位置能力 + 多个表示子空间 |
| 位置编码 | 每个输入嵌入加一个遵循 sin/cos 模式的向量；可外推到未见长度 |
| 残差 + LayerNorm | 每个子层周围有残差连接 + 层归一化（Add & Norm） |
| Decoder 侧 | masked 自注意力（掩掉未来位置 `-inf`）+ encoder-decoder attention（Q 来自下层，K/V 来自 encoder 输出） |
| Linear + Softmax | decoder 输出 → logits 向量（10k 单元）→ softmax → 选概率最高词 |
| 训练 | 交叉熵损失；贪心解码 vs 束搜索（beam_size 超参） |

## 为什么这么设计（逐机制逆推）

这是本文最有价值的部分——每个设计都能从"如果不用会怎样"推出来：

1. **为什么用 attention 不用 RNN/CNN？**
   - RNN：隐藏状态串行传递，长距离依赖被压缩进单个状态，难以并行；
   - CNN：卷积核局部视野，长距离依赖需要堆很多层；
   - Attention：每个位置直接"看"所有其他位置（$O(n^2)$ 计算换并行 + 直接连接），**训练可并行 → 训练快**。这是原文最强调的动机。

2. **为什么 Q/K/V 分离？**
   - 不是花哨，而是把"我要找什么（Query）"、"别人有什么（Key）"、"找到了给什么（Value）"三者解耦；
   - 没有它，就无法实现"q1 与所有 k 打分、再按分数聚合 v"的选择性聚合。

3. **为什么除以 $\sqrt{d_k}$？**
   - 原文说的"更稳定梯度"是结论；机制是：$q, k$ 各分量独立同分布时，点积方差 $\propto d_k$，不缩放会让 softmax 输入过大 → 梯度消失。这正是《Attention Residuals 推导笔记》里推过的 $\mathrm{Var}(q\cdot k)=d_k$ 的直接应用。

4. **为什么多头？**
   - 单一注意力会被当前词自身主导（$z_1$ 混合但可能偏自己）；
   - 多头 = 多个"表示子空间"，不同头关注不同关系（一个头关注 "animal"，另一个关注 "tired"）；
   - 本质是**集成学习在注意力维度上的体现**。

5. **为什么位置编码？**
   - Self-attention 对词序是"置换等变"的——不加位置信息，"it" 和 "animal" 互换表示不变；
   - sin/cos 编码可外推到未见长度（相对连续的位置信号）。

6. **为什么残差 + Norm？**
   - 残差解决深层退化（梯度通路），Norm 稳定分布——两者配合才能堆 6 层以上；
   - 这与 AttnRes 笔记里"残差流幅度控制"的动机一脉相承。

7. **为什么 decoder 要 mask？**
   - 自回归生成时不能"偷看未来"——训练时用 `-inf` 掩蔽强制因果性。

## 正反两面

**正面（这样设计的好处）**：
- 并行化直接带来训练速度优势（Google Cloud 推荐 TPU 参考模型）；
- 注意力是"软"的选择——每个位置都保留一点概率，梯度流更顺；
- 位置编码可外推，长度泛化优于固定窗口。

**反面 / 边界（如果不这样会怎样）**：
- **$O(n^2)$ 复杂度**：全注意力对长序列代价高——这正是后来 Sparse/Linear/Flash Attention 要解决的问题（见 Transformer Family 笔记）；
- **位置编码是"补丁"而非内建**：置换等变是 self-attention 的固有盲区，位置信息只能靠外加——后来 RoPE、ALiBi 都在改进这一点；
- **贪心解码易累积误差**：束搜索缓解但代价更高；
- **多头可解释性差**：原文自己承认"所有头加在一起更难解读"。

---

## 数学直觉（可带走的推导思维）

1. **"把串行变并行"的视角**：看到 RNN 的隐藏状态递推，就想想能不能让每个位置直接看到所有位置——这是 Transformer 的起点；
2. **归一化动机从方差来**：点积方差不稳定 → 除 $\sqrt{d_k}$。这个"先算方差、再定缩放"的套路可迁移到任何内积相似度场景；
3. **软性选择优于硬性选择**：softmax 保留全部位置的小概率 → 梯度不中断；
4. **"表示子空间"思维**：多头 = 让模型同时学多种关系投影，是容量扩展的廉价方式。

## 与我的关联

对照我的《Attention Residuals 推导笔记》，有几个直接印证：

- 笔记里推导的"除以 $\sqrt{d_k}$"（$\mathrm{Var}(q\cdot k)=d_k$）在这篇文章里就是"divide by 8 (the square root of the dimension of the key vectors)"——一个给直觉、一个给数学，互相补全；
- 笔记里"残差流幅度控制"的动机，对应这里的 Add & Norm——残差是深度的根基；
- 笔记里 AttnRes"把固定系数 $1$ 动态化"的思想，在这篇文章里能找到序列维度的镜像：固定递推 $1$ → 动态 $\alpha_{ts}$。两篇合起来看，"注意力 = 加权聚合"的统一框架就很清晰了。
