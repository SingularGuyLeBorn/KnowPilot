# 扩散 vs 自回归：全面对比

## 概述

「扩散语言模型能不能替代自回归？」——这是该领域被问最多的问题。本文不急于回答「谁更好」，而是从数学根基到工程实践，系统比较两种范式的十个关键维度。读完你会理解：扩散和自回归并非替代关系，而是两套不同 trade-off 的生成哲学，各有所长，未来更可能是融合而非二选一。

## 1. 数学定义：条件分解 vs 迭代去噪

两种范式的根本分歧在于**如何建模联合概率分布 P(x)**：

**自回归**（AR）将联合分布分解为条件概率的链式乘积：

$P_{\text{AR}}(x) = \prod_{i=1}^{n} P_\theta(x_i \mid x_{<i})$

**扩散**（Diffusion）则通过一个隐变量模型从噪声逐步生成：

$P_{\text{Diff}}(x) = \int p(x_T) \prod_{t=1}^{T} p_\theta(x_{t-1} \mid x_t) \, dx_{1:T}$

其中 x\_T 是纯噪声（或全 \[MASK]），x\_0 是最终生成的文本。

| 方面     | 自回归      | 扩散             |
| ------ | -------- | -------------- |
| 联合概率建模 | 精确分解，无近似 | 变分下界（ELBO），有近似 |
| 条件依赖方向 | 单向（左→右）  | 全局双向           |
| 数学完整性  | 理论上更「干净」 | 依赖步数 T 的近似精度   |

## 2. 推理效率

这可能是扩散模型最受关注的卖点——**并行生成**。

| 场景           | 自回归        | 扩散                             |
| ------------ | ---------- | ------------------------------ |
| 单 token 延迟   | O(1) 每次    | O(T) 总步数，但每步并行                 |
| 生成 n 个 token | n 次前向传播    | T 次前向传播（T << n 时胜）             |
| 实际加速比        | 基线         | MDLM: 3-5×; LLaDA: 2-8×（取决于 T） |
| KV-cache 依赖  | 必须         | 不需要（双向注意力）                     |
| 批处理效率        | 低（序列长度不一致） | 高（所有样本同时去噪）                    |

LLaDA 8B 实验显示：在 128 token 的短文本生成中，扩散模型比同规模 AR 模型快 2-8 倍。长文本场景下优势减小但依然存在。

但要注意：扩散模型的 latency 是 **固定 T 步**，而 AR 的 latency 与生成长度呈线性关系。对于极长文本（> 2000 token），AR 模型因 KV-cache 饱和反而可能更快。

## 3. 生成质量

| 指标            | 自回归                  | 扩散（当前最佳）                 |
| ------------- | -------------------- | ------------------------ |
| Perplexity    | 极低（LLaMA3 8B: \~6-8） | 接近但仍略高（LLaDA 8B: \~8-12） |
| 文本流畅度         | 极高                   | 高（偶有重复/不连贯）              |
| 多样性           | 可调（温度/top-p）         | 天然较高（随机噪声初始化）            |
| MMLU          | LLaMA3 8B: \~65%     | LLaDA 8B: \~60%+         |
| GSM8K（数学）     | 优势明显                 | 接近但仍有差距                  |
| HumanEval（代码） | 优势明显                 | 接近但仍有差距                  |

总体结论：**扩散模型在通用能力上已接近同规模 AR 模型**，差距在 5-10% 以内，且随着 LLaDA 2.0 等更大规模模型的推出在快速缩小。但在需要精确推理的任务（数学、代码）上，AR 目前仍有优势。

## 4. 训练效率

| 维度     | 自回归                            | 扩散                         |
| ------ | ------------------------------ | -------------------------- |
| 单步目标   | Next-token prediction（O(1) 采样） | 多步去噪（需采样 t 和噪声）            |
| 训练并行度  | 高（causal mask 内并行）             | 高（bidirectional + 随机 mask） |
| 数据效率   | 高                              | 中等（每一步/t 只训练一个噪声水平）        |
| 收敛速度   | 快                              | 较慢，通常需要更多训练步数              |
| 预训练数据量 | LLaMA3 8B: 15T tokens          | LLaDA 8B: 2.3T tokens      |

有趣的是：扩散模型训练时虽然单步计算更复杂（需采样 t 和 mask），但由于使用双向注意力而不是 causal mask，**每步可看到更多上下文**，在有限数据下反而可能有更好的样本效率。

## 5. 可控生成

这是扩散模型的**核心优势领域**。图像扩散中成熟的 guided generation 技术（classifier guidance、classifier-free guidance）可以自然地迁移到文本：

```text
# 概念：在去噪过程中注入约束
每一步去噪时：
  p_θ(x_{t-1} | x_t) · exp(λ · reward(x_{t-1}))
  其中 reward 可以是：情感分数、关键词覆盖率、长度约束等
```

自回归模型要做到类似效果，通常需要 RLHF、DPO 等额外训练阶段，或复杂的 prompt engineering。扩散模型则可以在推理时直接注入可微约束，无需额外训练。

Diffusion-LM 是这一方向的开创者，展示了在情感控制、主题引导等任务上远超同期 AR 模型的效果。

## 6. 反转诅咒与双向理解

**反转诅咒**（Reversal Curse）是自回归模型的结构性缺陷：模型从「A 是 B」学不到「B 是 A」，因为训练时只见过 A→B 的方向。扩散模型天然免疫此问题——每一步去噪时，所有位置都能看到彼此，不存在单向依赖。

LLaDA 用一个巧妙的诗歌补全实验证明了这一点：给定「床前明月光，\_\_\_」，GPT-4o 几乎只能往下续；而 LLaDA 同样可以补全前面的句子，因为它不区分「前」和「后」。

## 7. 长文本处理

| 方面    | 自回归                         | 扩散                           |
| ----- | --------------------------- | ---------------------------- |
| 生成长文本 | 天然适配（逐 token 续写）            | 挑战较大（T 步 × 全序列注意力 = O(T·n²)） |
| 理解长文本 | causal attention 限制         | 双向注意力，理论上更高效                 |
| 现有方案  | 成熟（RoPE、GQA、FlashAttention） | 尚在探索中                        |

长文本是目前扩散模型最明显的短板。生成一段 4096 token 的文本需要 T 步 × 4096² 的注意力计算，成本高昂。但双向注意力在长文本理解上可能更高效——这是未来融合的一个重要方向。

## 8. 幻觉与事实性

这是一个活跃的研究问题，尚无定论。初步观察：

* 扩散模型并行生成可能对全局一致性有优势（不太会出现「前后矛盾」的幻觉）
* 但自回归模型经过 RLHF 等大量对齐训练，在事实准确性上积累了丰富经验
* 扩散模型的对齐研究（RLHF for diffusion）才刚刚起步

## 9. 开源生态与基础设施

| 维度             | 自回归                         | 扩散                       |
| -------------- | --------------------------- | ------------------------ |
| 主流框架支持         | vLLM、TGI、Ollama、llama.cpp 等 | 几乎没有专用推理框架               |
| 社区规模           | 极大                          | 较小但快速增长                  |
| 预训练模型          | LLaMA、Qwen、Mistral 等数十个     | LLaDA 系列、少量开源            |
| HuggingFace 集成 | 完善                          | 初步（DiffusionLM pipeline） |

这是扩散模型目前最大的工程障碍：缺少生产级推理引擎。但考虑到社区对并行解码的热情，这一差距有望在 1-2 年内弥合。

## 10. 选型决策框架

| 你的需求               | 推荐                      |
| ------------------ | ----------------------- |
| 通用对话/写作，对延迟不敏感     | 自回归（成熟稳定）               |
| 低延迟批量生成（客服、翻译）     | 扩散（并行解码优势）              |
| 需要精细可控生成           | 扩散（guided generation）   |
| 需要双向理解（填空、纠错、改写）   | 扩散                      |
| 极长文本生成（> 4K token） | 自回归（当前更成熟）              |
| 数学推理、代码生成          | 自回归（仍有优势）               |
| 研究与探索              | 扩散（蓝海，大量 open problems） |

## 未来：融合而非二选一

已有工作开始探索两种范式的融合：

* **半自回归 + 扩散**：先扩散生成大纲/关键 token，再自回归填充细节
* **混合架构**：某些层用 causal attention，某些层用 bidirectional
* **扩散作为 AR 的推理加速器**：用扩散做 speculative decoding 的 draft model
