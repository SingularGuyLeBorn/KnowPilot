## 关于我

我是 **应知序**。

以前是自动化老哥，天天围着能源、煤炭、钢铁转。唯一跟「算」沾边的是运筹学和控制论——学了半截，吹牛够用，真干活不够。

后来赶上 vibe coding：初级程序员的手速和熟练度，很快被大模型碾平。我意识到怎么卷都卷不过模型，于是转向另一件事——**怎么跟 AI 更好写作、协作**。协作顺了一点之后，才开始想清楚：写代码不是目的，**做出东西**才是。

于是我一边当用户、一边写代码、一边测功能、一边写 PRD。见微（OasisMind）就是在这个过程里长出来的：花好几个月做出市面上「好像已经有」的东西，但过程中逐渐想明白——我想要什么。

## 见微解决什么

收藏太多，自己懒得整理。

内容散落各处，分类越拖越贵，拖到后面就彻底放弃。让 Agent 去做很合适；但 Agent 得跟我有点一样的品味——那就要自己蒸馏自己。这很难，总要做。见微希望成为常驻的数字主力：提醒、收集、筛选，宁可多收一点，再交给 Agent 过滤。

## 技术直觉

对 Agent，我更愿意把它想成控制论里的系统：**可控、可观测**，而不是黑盒魔法。浅色界面、炫一点的动效（含 Three.js / WebGL）是我喜欢的外表；本地 Markdown 是真相源。
