## 四、时间线 / 经历（新增字段：`timeline`）

按时间倒序列出关键节点。每个节点包含：

- 年份 / 时间段
- 标题
- 一句话说明
- （可选）标签：工作 / 项目 / 转折 / 学习

示例：

| 时间 | 标题 | 说明 |
|------|------|------|
| 2024-2026 | 见微 / OasisMind | 从想用 Agent 整理收藏，到花几个月落地一个本地优先的数字主力。 |
| 2023-2024 | 被大模型碾平 | 意识到初级程序员的熟练度正在贬值，转向学习如何与 AI 协作。 |
| 2019-2023 | 能源/自动化行业 | 围着煤炭、钢铁、运筹学和控制论转，学了半截，吹牛够用。 |

## 五、关注方向（已有 `focus`，可扩展）

每条从一句话扩成「标题 + 一句话解释」。例如：

- **跟 AI 协作把东西做出来**  
  写代码只是手段，最终要交付可用的东西。
- **见微 / OasisMind：收拾收藏债、蒸馏自己的品味**  
  收藏太多自己懒得整理，让 Agent 按我的偏好做初筛。
- **Agent 当作可控可观测系统**  
  不是黑盒魔法，是控制论直觉：输入、反馈、状态机、边界。
- **本地优先数字花园**  
  Markdown 是真相源，数据必须在自己手里。

## 十、理念（已有 `philosophy`，可扩展）

每条扩成一段小阐述，而不仅是一句口号。例如：

- **写代码不是目的，做出东西才是目的。**  
  一个能跑起来的原型胜过一百个漂亮的想法。代码是消耗品，交付物才是资产。
- **Agent 应该像控制论系统一样：完全可控、可观测。**  
  我不喜欢黑盒魔法。所有状态变化都应有日志、有边界、有终止条件。
- **宁可多收一点垃圾——反正有 Agent 再筛；关键是别丢。**  
  灵感过期就真没了，先丢进来，再让系统帮我归类和蒸馏。
- **粗鄙、偏颇没关系，只要还有点梦想。**  
  不完美是常态。重点是还在做，还在改。
- **我们的征途是星辰大海，但在那之前，不妨先去码头搞点薯条。**  
  宏大叙事很好，眼前的具体小事也值得认真做完。

## 十二、bodyMarkdown 长文（已有，可大幅扩展）

这是 about 页面最重要的正文区，可以写长一点。建议结构：

1. **我是谁**（200-400 字）
2. **我在做什么**（200-400 字）
3. **我为什么做见微**（300-500 字）
4. **我的技术直觉**（200-400 字）
5. **现在关心的事**（200-400 字）
6. **怎么联系我**（100 字）

可以插入：
- `![图片](...)`
- ` ```html ` 代码块（会被渲染成可预览的 HTML）
- 链接、列表、引用
