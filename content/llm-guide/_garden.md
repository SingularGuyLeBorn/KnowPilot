# LLM 指南

面向工程师与研究者的大语言模型全栈知识库，覆盖原理、训练、优化、应用与前沿。

## 本库定位

这不是科普快餐，也不是 API 说明书。目标是构建**面向从业者的、具备极限深度的技术知识库**：公式推导、代码对照、演进家谱。

与「博客」(posts) 花园分离：博客放对外长文与随笔；本库放系统化 LLM 教程与精读。

## 快速入口

打开本库后用左侧目录浏览完整树；总索引见文章 [LLM 指南](/posts/llm-guide?garden=llm-guide)。
