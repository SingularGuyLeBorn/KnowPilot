# 实验模块时间盒

> 个人实验场纪律：功能可以多，但每个坑必须有**验收标准**和**到期日**。到期未达标 → 标 `experimental` 冻结，禁止无限调试拖垮主线。

## 规则

1. 新开实验先在本表占一行（模块 / 验收 / 到期 / 状态）。
2. 到期日默认 **14 天**；到期未绿则冻结（代码可留，不再投入调试时间），除非主动续期一次（再 7 天）。
3. 「验收」必须是可演示的一句话（例如「子 Agent 三步任务能 report_back」），禁止「继续完善」。
4. 冻结后改主线（Chat / 博客 / 本地模型闭环）优先；解冻需新验收句。

## 状态枚举

- `active`：投入中  
- `done`：验收通过，收进主线  
- `freeze`：到期或主动冻结  
- `drop`：放弃（可删代码或留注释）

## 与主线的边界

| 主线（不进时间盒） | 实验（进本表） |
|--------------------|----------------|
| Markdown ↔ SQLite、博客编辑阅读 | Swarm 分布式协作细节 |
| Chat 三层 Store 不变量 | 新通道（企微/QQ）接入 |
| 本地/云 LLM provider 路由 | 新抓取平台 / OCR 花活 |
| 附件按 postId 落盘 | 邮件审批 UX 打磨 |

更新本表时改「到期 / 状态」即可，不必写长报告。
