# 持续学习与大语言模型：综述

持续学习（Continual Learning，CL），又称终身学习（Lifelong Learning）或增量学习（Incremental Learning），旨在使模型能够像人类一样，从不断到来的新数据、新任务中学习新知识，同时保持对旧知识的记忆。在经典深度学习中，这一问题主要围绕图像分类与强化学习展开，核心挑战是“灾难性遗忘”（Catastrophic Forgetting）：当模型在序列数据上依次训练时，新任务的梯度更新会覆盖旧任务所学的参数分布，导致旧任务性能急剧下降。进入大语言模型（Large Language Models, LLMs）时代，持续学习被赋予了新的内涵与挑战。一方面，LLM 的参数规模、训练成本与对齐复杂度使得频繁全量重训练变得不可行；另一方面，现实世界要求模型不断更新知识、习得新技能、适配新领域，并在多轮后训练阶段保持通用能力与安全对齐。因此，研究如何在 LLM 中实现低成本、稳定且可扩展的持续学习，成为连接学术研究与工业部署的关键课题。

本文面向具备机器学习基础的技术读者，系统梳理持续学习的核心概念、经典方法分类、LLM 时代的新挑战与新方法、代表性评估基准及未来方向。全文引用基于截至 2026 年 8 月的公开文献，重点参考 Wu 等人[^1]、Shi 等人[^2]、Guo 等人[^3] 的综述，以及 TRACE[^4]、CIBT[^5] 等基准工作。

## 1. 核心概念与问题形式化

### 1.1 灾难性遗忘

灾难性遗忘最早由 McCloskey 与 Cohen 在连接主义网络中观察到，指的是神经网络在学习新任务后，先前任务表现显著下降的现象。其机理在于，深度网络的参数空间被后续任务的优化过程“重写”，而旧任务的最优解在新样本的梯度方向上不再占优。在 LLM 中，遗忘不仅表现为具体事实或分类能力的丢失，还可能表现为通用指令跟随能力、数学推理能力、代码生成能力、安全性以及对齐行为的退化。例如，TRACE 基准显示，在持续指令微调后，Llama-2-Chat-13B 在 GSM8K 上的准确率从 28.8% 骤降至 2%[^4]。这说明，对于已经对齐的 LLM，持续学习不仅威胁垂直领域性能，还可能破坏其基础能力。

### 1.2 稳定性–可塑性困境

持续学习需要在两个相互冲突的目标之间取得平衡：可塑性（plasticity）要求模型能够迅速吸收新知识；稳定性（stability）要求模型不破坏已有知识。这一矛盾被称为稳定性–可塑性困境（Stability-Plasticity Dilemma）。在 LLM 中，过度强调稳定性会导致模型对新数据“视而不见”，失去适应能力；过度强调可塑性则会造成通用能力崩解、安全边界模糊。不同场景对二者的权重不同：医疗、法律等高风险领域要求稳定性优先；产品快速迭代、新闻资讯等场景则更强调可塑性。因此，持续学习方法往往通过正则化、记忆回放、参数隔离、数据混合等机制，显式控制这一权衡。

### 1.3 持续学习场景

传统持续学习通常按任务边界是否已知、标签空间是否变化划分为三类：

- **任务增量学习（Task-Incremental Learning, Task-IL）**：任务身份在训练和测试时均已知，模型可针对每个任务使用独立输出头或任务嵌入。
- **领域增量学习（Domain-Incremental Learning, Domain-IL）**：任务身份未知，但所有任务共享同一标签空间，主要挑战是分布漂移。
- **类增量学习（Class-Incremental Learning, Class-IL）**：任务按类别逐步到来，测试时无任务身份，模型必须同时识别所有已见类别。

在 LLM 中，场景更为复杂。指令微调数据通常没有明确的任务边界，而是按领域、能力、语言、工具或时间顺序到来；因此“无任务边界”（task-free）设定更为常见。Wu 等人[^1]将 LLM 的持续学习划分为三个阶段：持续预训练（Continual Pre-training）、持续指令微调（Continual Instruction Tuning）和持续对齐（Continual Alignment），每个阶段的数据形态、优化目标与遗忘机制各不相同。Guo 等人[^3]进一步将其扩展到生成式 AI，包括多模态大模型、视觉-语言-动作模型乃至扩散模型。

## 2. 经典持续学习方法

在进入 LLM 时代之前，持续学习已在计算机视觉领域形成三大主流范式：正则化、回放与架构隔离。这三大范式仍然是理解当前 LLM 持续学习方法的基础。

### 2.1 正则化方法

正则化方法通过约束参数更新，使新知识的学习尽量不破坏旧知识。Kirkpatrick 等人提出的弹性权重巩固（Elastic Weight Consolidation, EWC）[^6] 使用 Fisher 信息矩阵估计每个参数对旧任务的重要性，并在新任务训练时对这些参数施加二次惩罚。随后，Synaptic Intelligence（SI）[^7]、Memory Aware Synapses（MAS）[^8] 等方法改进了重要性估计的效率与稳定性。另一类代表性方法是学习 without Forgetting（LwF）[^9]，它利用旧模型的软目标（soft target）对旧任务进行知识蒸馏，无需存储旧数据。这些方法在小模型与中等规模任务上表现良好，但在 LLM 中面临根本困难：数十亿参数的重要性估计不稳定，且对预训练阶段所蕴含的庞杂知识难以用单一矩阵刻画。

### 2.2 回放与记忆方法

回放（Replay）方法通过保存或生成旧任务样本，在新任务训练时混合旧数据，从而直接缓解遗忘。iCaRL[^10] 提出使用 herding 选择代表性样本，并配合最近类均值分类器。后续工作发展了经验回放（Experience Replay）、生成回放（Generative Replay，使用生成模型合成旧样本）以及基于特征的记忆库。在 LLM 中，回放尤为重要，因为预训练语料与指令数据可被存储和重采样；然而，存储原始数据涉及隐私、合规与存储成本，且 LLM 的遗忘往往发生在通用能力层面，单纯回放旧领域数据不足以维持这些能力。因此，LLM 时代的回放方法发展为更复杂的数据混合、重采样与合成策略。

### 2.3 架构与参数隔离方法

架构方法为不同任务分配独立的参数子集或网络模块，从根本上避免参数冲突。Progressive Neural Networks（PNN）[^11] 为每个任务新增一列网络，并通过侧向连接复用旧知识。PackNet、HAT 等工作进一步利用网络剪枝与掩码，在固定网络容量内隔离任务。参数隔离类方法在稳定性上具有优势，但会随任务数量线性增长参数量，部署成本高。在 LLM 中，这一思路演变为参数高效微调（PEFT）模块与模块化专家系统，通过为每个任务或领域添加少量可训练参数，在容量与稳定性之间取得平衡。

### 2.4 元学习与动态优化方法

元学习（Meta-Learning）方法旨在让模型“学会学习”，通过优化初始参数或学习率，使模型在少样本新任务上快速适应并减少遗忘。MAML 及其变体、Meta-Consolidation（MC-SGD）等尝试通过任务级元信息设计更新规则。动态优化方法则根据任务相似度、损失景观或梯度冲突动态调整学习率、优化方向。这些方法在少样本持续学习场景下有效，但应用于 LLM 时仍面临训练不稳定与计算成本问题。

## 3. 大语言模型时代的持续学习

大语言模型的持续学习与传统 CV 场景存在本质差异：模型规模巨大、数据以文本和指令为主、通常已通过对齐获得通用能力，且更新往往发生在预训练之后的后训练阶段。以下从七个方向展开讨论。

### 3.1 持续预训练（Continual Pre-training）

持续预训练指在已有基础模型之上，继续用新的无标注或弱标注文本进行下一个token预测（Next-token Prediction）。它用于让模型吸收最新知识、适配特定领域或语言。Xie 等人[^12] 研究了高效持续预训练以构建领域专用 LLM，发现数据选择、学习率重预热（learning rate rewarming）与混合比例至关重要。Yıldız 等人[^13] 的工作则指出，不同模型族在持续预训练中的遗忘行为差异显著：部分模型持续改进，部分则出现通用能力退化。Li 与 Lee[^14] 进一步发现，在已对齐 LLM 上进行持续预训练可能破坏对齐与输出行为。因此，持续预训练不仅是“继续训练”，更涉及数据质量、领域相关性、学习率调度与灾难性遗忘的精细控制。

### 3.2 持续指令微调（Continual Instruction Tuning, CIT）

持续指令微调是 LLM 持续学习中最受关注的场景。与预训练不同，指令微调数据以（指令、输出）对的形式出现，且通常按领域或能力顺序到来。CIT 的目标是让模型在习得新指令分布的同时，保持通用指令跟随、安全对齐与旧领域性能。TRACE 基准[^4] 是这一领域的代表性工作，它包含八个覆盖领域任务、多语言、代码生成与数学推理的数据集，并发现简单顺序微调会导致通用能力显著下降。为应对此问题，TRACE 提出了 Reasoning-augmented Continual Learning（RCL），通过在训练中加入推理路径，显著降低遗忘。CIBT 基准[^5] 则专注于持续指令调优（Continual Instruction Tuning）设定，提供了更细粒度的任务序列与评估指标。Zhang 等人[^5] 的工作也强调，数据顺序、任务相似度与回放比例对最终性能影响巨大。

### 3.3 对齐阶段的持续学习

LLM 通常经历预训练、监督微调（SFT）与基于人类反馈的强化学习（RLHF）或偏好优化（DPO）。在部署后，模型可能需要继续基于用户反馈或新偏好进行对齐更新。然而，对齐阶段的持续学习面临“对齐税”（alignment tax）问题：为优化新偏好可能牺牲原有安全性、有用性或事实性。Fernando 等人[^15] 研究了 SFT 与 DPO 序列组合中的遗忘，发现简单顺序对齐会同时损害通用能力与旧偏好。因此，对齐阶段的持续学习需要谨慎设计奖励模型、偏好数据回放与策略正则化，以避免价值观漂移。

### 3.4 参数高效持续学习（PEFT-based CL）

由于 LLM 全量微调成本极高，参数高效微调（PEFT）成为持续学习的主流基座。LoRA[^16] 通过低秩矩阵注入可训练参数，使模型在保持主干冻结的同时适应新任务。在持续学习设定下，研究者发展了多种 LoRA 变体：

- **O-LoRA**（Orthogonal Subspace Learning）[^17]：为每个任务学习正交低秩子空间，减少任务间参数干扰。
- **SATP**[^18]：通过共享注意力模块学习并选择参数高效模块块，实现任务无关的鲁棒适应。
- **LoRAMoE**[^19]：在冻结主干上引入 MoE 风格的 LoRA 适配器，通过路由机制动态选择专家。
- **MoE-CL**[^20]：采用对抗混合专家框架，为每个任务设置独立 LoRA 专家以保存任务知识，同时通过共享专家与判别器实现跨任务迁移。
- **I-LoRA**[^21]：维护快慢双 LoRA 适配器，分别对应短期可塑性与长期记忆。

这些方法共同证明：通过小参数模块的隔离、正交约束、路由与复用，可以在LLM上实现较稳定的持续适应，同时显著降低训练与部署成本。然而，PEFT 的容量有限，对于需要大量新知识注入的场景，仍可能出现“容量饱和”问题。

### 3.5 回放与数据混合策略

在 LLM 持续学习中，数据混合（Data Mixing）是比传统“回放”更普适的概念。它通过将新数据与旧数据、通用数据、对齐数据按比例混合，直接控制遗忘程度。关键问题包括：混合比例、数据选择、采样权重、任务顺序与重复次数。OP-Mix[^22] 等工作提出基于优化的数据混合策略，以在多个任务间取得最佳平衡。在工业部署中，通常会保留一份“通用能力维持数据”（general capability retention data），在每次领域更新时混合一定比例，防止通用能力崩溃。此外，由于存储原始对话数据可能涉及隐私，研究者也探索使用模型生成合成样本、特征级记忆或蒸馏信号进行“无数据回放”（data-free replay）。

### 3.6 模块化与专家模型

模块化（Modularity）与混合专家（Mixture-of-Experts, MoE）为持续学习提供了另一条路径：通过为不同任务、领域或能力分配独立专家模块，避免在同一参数空间上冲突。Shazeer 等人[^23] 提出的 MoE 为大规模模型稀疏扩展提供了基础。近年来，MoE 被用于持续学习：例如，LIMoE[^24] 针对图像-文本多模态场景设计专家；MoLE-CIE[^25] 在信息抽取任务中持续训练 LoRA 专家；MoSE（Mixtures of SubExperts）[^26] 将模型能力分解为可复用、可组合的子专家，实现模块化持续学习。模块化方法的优势在于可扩展性与可解释性：新增任务只需添加或更新少量专家，旧专家可冻结保留。然而，路由机制的设计、专家容量分配与负载均衡仍是开放问题。

### 3.7 知识编辑与持续模型编辑

知识编辑（Knowledge Editing, KE）关注如何在不重训整个模型的情况下，修改或更新模型中的特定事实知识。与持续学习不同，知识编辑通常处理离散的、可明确描述的事实更新（如“某国总统换人”），而持续学习处理更广泛的分布与能力变化。然而，两者在实践中日益融合：模型需要在生命周期中持续更新大量事实。Wang 等人[^27] 的知识编辑综述将方法分为基于外部记忆、基于元学习与基于定位-编辑三大类。在持续编辑（lifelong knowledge editing）场景下，Zhang 等人[^28] 的 WikiBigEdit 研究揭示了现有编辑方法在大量连续更新时的稳定性与泛化限制。Wang 等人[^29] 提出的 WISE 通过重新设计知识记忆机制，试图在支持新编辑的同时保留旧知识。知识编辑与持续学习的关系正在从“并行的两条线”走向“融合”：未来的 LLM 可能需要同时处理能力演进、分布漂移与事实更新。

### 3.8 非参数路径：上下文学习与检索增强

除了修改模型参数，另一条持续学习路径是保持参数冻结，通过上下文学习（In-Context Learning, ICL）或检索增强生成（Retrieval-Augmented Generation, RAG）引入新信息。这种方法不改变模型权重，因此天然不存在灾难性遗忘，但受限于上下文长度、检索质量与知识更新粒度。RAG 将外部知识库作为持续学习的“外部记忆”，适用于事实更新频繁但模型能力不需要改变的场景。然而，对于需要习得新能力（如新的工具调用模式、新的编程语言或新的推理风格）的场景，仅靠 RAG 不够，仍需参数更新。因此，参数更新与非参数记忆的结合成为研究热点：例如，通过 RAG 提供事实，通过 LoRA 模块学习技能，通过路由机制决定何时依赖外部记忆、何时依赖模型内部知识。


## 4. 评估基准与指标

### 4.1 代表性基准

持续学习的评估需要在“学习新任务”与“记住旧任务”之间取得平衡。传统 CV 基准如 CIFAR-100、ImageNet-100/1000 的分割序列（Split CIFAR-100、Split ImageNet）仍是经典设定，但它们针对图像分类，与 LLM 的文本生成场景差异较大。LLM 时代涌现出一批面向文本理解与指令跟随的持续学习基准：

- **TRACE**[^4]：面向对齐后 LLM 的持续学习综合基准，包含八个挑战性数据集，覆盖领域任务、多语言、代码生成与数学推理。TRACE 强调通用能力保持，其实验表明简单顺序训练会严重破坏原有能力，并提出了 RCL 缓解策略。
- **CIBT**[^5]：专注于持续指令微调（Continual Instruction Tuning）的基准，提供多样化的指令任务序列，用于评估模型在持续获取新指令能力时的遗忘与迁移。
- **Continual-News**[^30]：基于新闻文本的持续预训练/持续指令微调基准，按时间顺序组织年度新闻数据，适合评估时间漂移与领域演进。
- **CLiMB**[^31]：面向多任务指令遵循的持续学习基准，关注任务顺序、任务相似度与跨任务迁移。
- **Long Sequence Benchmarks for LLM Evaluation**：部分工作通过长序列事实问答（如 Wikidata 时间线、HotpotQA 变体）评估模型在持续更新后的长期记忆与事实一致性。
- **WikiBigEdit**[^28]：用于终身知识编辑的基准，通过大规模连续事实编辑评估编辑方法在序列更新中的稳定性、泛化性与副作用。

这些基准共同推动了从“任务级准确率”向“综合能力保持 + 新知识获取 + 稳定性–可塑性权衡”多维评估的转变。

### 4.2 评估指标

持续学习常用以下指标：

- **平均准确率（Average Accuracy, Avg.Acc）**：所有已见任务在最终模型上的平均性能，是最直接的综合指标。
- **遗忘率（Forgetting Rate）**：旧任务在训练新任务后性能下降的平均幅度，衡量灾难性遗忘的严重程度。
- **新任务准确率（New Task Accuracy, New.ACC）**：模型在最新任务上的性能，衡量可塑性。
- **后向迁移（Backward Transfer, BWT）**：学习新任务后对旧任务性能的影响，负值表示遗忘。
- **前向迁移（Forward Transfer, FWT）**：旧任务学习对新任务初始性能的促进。
- **稳定性–可塑性面积（Stability-Plasticity Area）**：通过绘制不同方法在遗忘率与新任务准确率上的帕累托前沿，评估整体权衡。
- **通用能力保持率（General Capability Retention）**：在通用基准（如 MMLU、GSM8K、HumanEval、BBH）上的性能保持，特别适用于 LLM。
- **知识一致性（Knowledge Consistency）**：在知识编辑与事实更新场景中，评估模型对更新事实的一致回答能力。
- **计算与存储开销（Training Cost / Memory Overhead）**：对于 LLM，训练成本、可训练参数量、专家数量与存储开销是工程落地的核心指标。

在 LLM 评估中，还需关注**对齐保持**（helpfulness、harmlessness、truthfulness）与**输出行为稳定性**（如输出格式、拒绝率、安全性）。单一准确率不足以刻画持续学习对对齐 LLM 的影响，必须综合评估。

## 5. 未来方向

持续学习与大语言模型的结合仍处于快速发展阶段。以下几个方向值得重点关注。

### 5.1 自演化与自主学习

未来 LLM 不应仅被动接收数据，而应能够自主识别需要学习的信号、生成训练数据、评估自身不足并主动更新。Self-Evolving LLMs[^20]、A-Evolve[^32] 等工作探索了通过自生成监督与执行反馈实现自我演进的路径。这要求持续学习系统具备闭环能力：观察环境、发现分布漂移、采集或生成数据、局部更新、验证并保持旧能力。自演化也带来了新的风险：如果模型自主更新缺乏审计与对齐约束，可能引发价值观漂移或能力失控。

### 5.2 多模态与具身持续学习

随着多模态大语言模型（MLLM）、视觉-语言-动作模型（VLA）与扩散模型的发展，持续学习正从文本扩展到图像、视频、音频、3D、机器人动作与传感器数据。Guo 等人[^3] 的综述系统梳理了 LLM、MLLM、VLA 与扩散模型中的持续学习方法。多模态持续学习面临模态对齐、跨模态遗忘、数据异构性与实时性等新挑战。在具身智能与机器人领域，持续学习使智能体能够在不断变化的环境中积累经验，同时避免对旧技能或旧环境的灾难性遗忘。

### 5.3 工具使用与智能体持续学习

LLM 正从对话模型演变为可使用工具、调用 API、执行代码的智能体。智能体持续学习涉及：新工具接入、工具调用模式更新、长期记忆管理、多轮规划策略演进等。Agent 系统需要持续学习如何在新的 API、新的环境约束与新的用户偏好下完成任务，同时保持对旧工具与旧流程的可靠性。这要求持续学习机制与工具注册、记忆检索、审批与反馈回路深度集成。

### 5.4 遗忘诊断、可解释性与审计

理解和度量遗忘是设计有效缓解策略的前提。未来需要更精细的遗忘诊断工具：哪些层、哪些神经元、哪些知识在持续学习中发生变化？Zheng 等人[^33] 研究了持续学习语言模型中的“伪遗忘”（Spurious Forgetting）现象，指出部分性能下降并非真正的知识丢失，而是输出分布变化导致。更准确的遗忘归因、基于可解释性方法的脆弱区域定位、以及更新前后的差异审计，将帮助开发更安全的持续学习系统。

### 5.5 轻量化、隐私与合规部署

工业部署中，持续学习必须满足低训练成本、低存储开销、低延迟与隐私合规要求。参数高效方法、模块化专家、量化与蒸馏、边缘-云端协同训练等方向将持续受到关注。同时，持续学习涉及用户数据、模型更新与知识库变更，需要符合数据最小化、可遗忘权（Right to be Forgotten）、审计追踪与版本管理等合规要求。设计可撤销、可回滚、可审计的持续学习系统，是实现可信 LLM 长期部署的关键。

### 5.6 知识编辑、RAG 与参数更新的融合

未来的 LLM 可能同时维护三层知识：冻结参数中的通识、可更新的 PEFT 模块中的技能与领域能力、外部检索系统中的实时事实。知识编辑、RAG 与参数持续学习将不再是相互替代的方案，而是统一的“终身知识管理系统”的不同层级。研究如何自动判断某条新知识应该写入参数、写入专家模块、还是写入外部记忆，如何实现三层之间的一致性与冲突消解，是极具潜力的方向。

## 6. 结论

持续学习是使大语言模型从“一次性训练”走向“终身可用”的核心能力。从经典深度学习中的灾难性遗忘、稳定性–可塑性困境，到 LLM 时代的持续预训练、持续指令微调、对齐保持、参数高效适应、模块化专家与知识编辑，研究范式已经发生了深刻转变。LLM 的庞大规模、昂贵训练成本与复杂对齐状态，使得传统全量微调与简单正则化不再适用，低成本、可扩展、可审计的混合方法成为主流。TRACE、CIBT、WikiBigEdit 等基准推动评估从单一任务准确率向综合能力保持、迁移、遗忘与开销多维转变。面向未来，自演化、多模态、智能体工具使用、遗忘诊断与合规部署将持续推动该领域发展。持续学习不仅是技术问题，更关乎 LLM 能否安全、可靠、负责任地长期服务现实世界。因此，在算法创新之外，建立统一的评估协议、开放的标准化基准、清晰的版本治理与可审计的更新机制，同样是该领域走向成熟的必由之路。只有将性能、效率、安全与可控性置于同等重要的位置，持续学习才能真正成为大语言模型从实验室走向长期生产环境的基础设施。
