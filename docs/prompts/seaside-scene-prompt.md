# 海边场景生成 Prompt

> 用途：让别人（AI 或人类创作者）生成一个「面前是大海」的海边场景。
> 核心要求：给出氛围和结构，但不要限制创作者的发挥空间。

## 基础氛围

一幅**海边日落/黄昏**的场景，视角是从沙滩或海岸边向海面望去，**面前就是大海**。

- 天空：渐变色彩，从靠近海平面的暖橙、粉紫，过渡到上方的深蓝或暗紫。可以有几缕被夕阳染红的云。
- 海面：有层次感，远处平静，近处泛起细碎的波光。夕阳的倒影在海面上拉成一条金色的光路。
- 沙滩：前景是沙滩，可以有细腻的沙粒纹理，也可以有几块石头、贝壳、脚印或一双随意脱下的拖鞋。
- 动态：海面的波光在闪烁，云层在缓慢流动，海浪轻轻起伏。

## 情绪关键词

孤独、辽阔、治愈、摆烂、浪漫、渺小但自由。

## 可选元素（不要全部堆砌，创作者根据感觉挑选）

- 一个人坐在沙滩上，背对镜头，看着海。
- 一只海鸥停在礁石上，或从天空飞过。
- 远处有一艘小船，或一座灯塔的微光。
- 海边有一张旧木椅、一条毯子、一杯喝了一半的饮料。
- 星空开始在海天交界处若隐若现。
- 海浪冲上沙滩，留下白色的泡沫，又慢慢退去。

## 风格提示

- 可以是写实的、插画的、低多边形的、像素风的、油画质感的、赛博朋克色调的……不限制。
- 色调冷暖对比强烈一点，黄昏的金色和海的深蓝/紫形成对比。
- 画面要有呼吸感，不要做得太满，留出天空和海面的空间。

## 创作者自由

**以上只是参考框架。请创作者自由发挥：** 改变时间（清晨/深夜/暴风雨前）、改变季节、加入自己的意象、调整构图、换风格。重点是让人一看就想坐下来，什么都不想，先看一会儿海。
